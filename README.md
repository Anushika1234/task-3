# This project implements a real-time age and gender detection system for a horror roller coaster. It uses a pre-trained machine learning model to predict the age and gender of individuals, allowing only those between the ages of 13 and 60 to board. The system also logs the detected data (age, gender, entry time) into a CSV file.

1-Features
Real-time age and gender detection using a pre-trained model

Eligibility check for age (13–60)

Data logging into a CSV file

Face detection with OpenCV

2-Technologies
TensorFlow/Keras, OpenCV, Pandas, Python
